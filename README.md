# 🛍️ Loja do Aluno – Python + MongoDB

Breve descrição do projeto aqui. Este sistema foi desenvolvido para gerenciar uma loja virtual simulada, integrando o Python ao banco de dados NoSQL MongoDB.

## 🚀 Tecnologias Utilizadas
- Python 3
- MongoDB (Cloud / Atlas ou Local)
- GitHub Codespaces

## ⚙️ Funcionalidades
- [ ] Conexão segura com o banco de dados.
- [ ] Cadastro de novos itens (`inserir.py`).
- [ ] Consulta de registros existentes (`consultar.py`).
- [ ] Atualização de dados (`atualizar.py`).
- [ ] Remoção de informações (`excluir.py`).

## 📁 Estrutura do Projeto
```text
python-mongodb-loja/
├── app.py
├── conexao.py
├── consultar.py
├── inserir.py
├── atualizar.py
├── excluir.py
├── .env
├── .gitignore
├── README.md
└── requirements.txt
```

## 🛠️ Como Executar

1. Clone o repositório ou abra no Codespaces.
2. Instale as dependências necessárias:
   ```bash
   pip install -r requirements.txt
   ```
3. Configure as suas credenciais do MongoDB no arquivo `.env`.
4. Execute o aplicativo principal:
   ```bash
   python app.py
   ```
